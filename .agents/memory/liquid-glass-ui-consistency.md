New interface components in this app should follow the existing liquid glass design.

**Why:** The user explicitly asked that every new component match the current liquid glass style.

**How to apply:** Reuse the established glass surfaces and interaction treatments for new controls, cards, overlays, and attachment UI instead of introducing flat or unrelated materials.
